# Web Multimedia API Project

A simple web application built using HTML, CSS, and JavaScript that demonstrates the core Web Multimedia APIs, including the MediaDevices API for camera streaming, the HTML5 Audio element, and the Canvas API for capturing snapshots.

## Features

- **Live Webcam Access:** Start and stop live camera feed using `navigator.mediaDevices.getUserMedia`.
- **Audio Playback:** Built-in HTML5 audio player for streaming audio.
- **Snapshot Capture:** Capture and render a still image from the live video stream onto a Canvas element.

## Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
